# 🎬 Video Text Converter

Công cụ giúp **chuyển đổi giữa Video và Text** với giao diện đơn giản, dễ sử dụng.

---

## ✨ Tính năng chính

### 🎥 Video → Text
- Chuyển âm thanh trong video thành văn bản
- Hỗ trợ nhiều ngôn ngữ (Việt, Anh, Trung)

### 📝 Text → Video
- Tạo video từ nội dung text
- Có hiệu ứng hiển thị chữ (gõ chữ hoặc hiển thị toàn bộ)
- Tùy chỉnh kích thước và font chữ

### 🖥️ Giao diện
- Dễ sử dụng, trực quan
- Có thanh tiến trình và log xử lý
- Chọn file/thư mục nhanh chóng

---

## ⚙️ Yêu cầu

- Python 3.6+
- Có kết nối Internet
- RAM từ 4GB

---

## 📦 Cài đặt

Cài thư viện cần thiết:

```bash
pip install moviepy speechrecognition pydub numpy```
Cài thêm ImageMagick (bắt buộc để tạo video)

---

## 🚀 Cách sử dụng
 1. Mở chương trình
 2. Chọn chức năng:
  - Video → Text
  - Text → Video
 3. Chọn file và thư mục lưu
 4. Nhấn Bắt đầu xử lý"# mp3_to_video_text"
